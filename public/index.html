Butler

An on-device agentic yield rebalancer. The model proposes; deterministic guardrails and the user decide; WDK executes on Base.

Deposit

Network: Base (chain 8453) (test on Base Sepolia 84532 first).

Accepted asset: USDC. A small amount of ETH is needed for gas.

Your wallet address (derived from your own seed):

Set WDK_SEED in your environment, then run: node scripts/sepolia-check.mjs (prints address)

Warning: send only USDC and ETH on Base. Other tokens or chains may be lost.

Run the full flow in the terminal: npm run run -- --source live --executor live

Safety

      
    
        
  • The model only chooses among pre-validated candidate moves (forced JSON schema, temperature 0).
    • 
        
  • Guardrails enforce known venues, caps, APY gaps, gas reserve, and snapshot freshness.
    • 
        
  • `MAX_USDC_PER_TX` ceiling, exact-amount approvals only.
    • 
        
  • Offline: decision is guardrailed and queued; replay re-validates against fresh state before broadcast.
    • 
        
  • Confirmation requires typing yes exactly.
